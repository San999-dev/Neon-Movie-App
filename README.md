Neon Movie App 🌌🎬

Neon Movie App is a stylish, neon-themed web application to explore trending movies, search for films, and view details with interactive modals. It features responsive design, 3D neon hover effects, and live search suggestions.

Features ✨

Neon Themed UI – Vibrant neon glow effects for headers, buttons, and cards.

Trending Slider – Smooth scrolling slider with 3D hover effects.

Live Search Suggestions – Instant suggestions while typing.

Movie Grid – Responsive layout displaying search results.

Movie Details Modal – Click a movie to see IMDB rating, year, and trailer.

Genre Filters – Filter movies by Action, Comedy, Drama, Horror, Romance, or All.

Responsive Design – Fully functional on mobile, tablet, and desktop.

Loading Indicators – Shows “Searching…” while fetching data.

Usage 🎬

Type a movie name in the search bar and press Enter or click Search.

Hover over trending movies for 3D neon effects.

Click a movie to view details in a modal.

Use the genre filters to refine results.

Click Watch Trailer to open YouTube.
